## `README.md`

这里存放一些我与动漫有关的内容。它们可能是认真写下的作品分析，也可能是突然触发的角色研究、观后感、吐槽，以及无法通过常规类型系统检查的精神活动。

本仓库不限定作品，也不要求所有文章保持同一种风格。唯一可以确定的是：内容由兴趣驱动，更新取决于灵感、观看进度和现实世界的空闲线程。

## 内容类型

- **正经分析**：关于作品、人物、叙事和主题的认真讨论。
- **非正经研究**：格式可能很严谨，研究对象和结论则不一定。
- **观后日志**：观看过程中的感想、记录与阶段性输出。
- **未定义行为**：暂时无法归类，但删除又觉得可惜的内容。
